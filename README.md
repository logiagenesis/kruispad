# Kruispad Hazeldean

Statiese herbou van [kruispadhazeldean.co.za](https://www.kruispadhazeldean.co.za/) met Astro, TypeScript en Tailwind. Uitvoer is staties en word na GitHub Pages ontplooi.

Produksie: https://logiagenesis.github.io/kruispad/

```bash
npm install
npm run dev
npm run qa
```

`BASE_PATH=/kruispad` word in GitHub Actions gestel. Lokaal is die basis `/`.
